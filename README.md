# Transferencia-Introduccion-Lenguajes-Internet

Un repositorio hecho para la actividad colaborativa de transferencia de la materia Introducción a los Lenguajes de Internet de UCompensar.



# Hoja de Vida Web

## Descripción
Este proyecto consiste en la creación de un sitio web personal orientado a presentar información académica, profesional y personal de manera organizada, atractiva y accesible a través de Internet.

La aplicación fue construida utilizando tecnologías fundamentales del desarrollo web como HTML y CSS, aplicando conceptos de estructura de contenido, diseño visual, enlaces internos, imágenes, tablas y organización mediante contenedores. Adicionalmente, el proyecto se encuentra publicado mediante GitHub Pages para permitir su acceso público desde cualquier navegador.


## Objetivos
 - Crear un sitio web personal con fines de presentación profesional.
 - Aplicar conceptos de HTML para estructurar contenido.
 - Implementar estilos CSS para mejorar la experiencia visual.
 - Organizar información mediante divisiones, listas, tablas e imágenes.
 - Publicar el proyecto utilizando GitHub como servicio de alojamiento web.


## Tecnologías utilizadas
 - HTML5
 - CSS3
 - GitHub
 - GitHub Pages


## Características
 - Página principal de presentación personal.
 - Información académica y profesional.
 - Uso de imágenes y elementos multimedia.
 - Navegación mediante enlaces internos.
 - Diseño personalizado con CSS.
 - Publicación en línea mediante GitHub Pages.
